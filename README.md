# marotta.ch

Site vitrine de **Marotta Consulting** — conseil en assurance, prévoyance et finance.

Site statique (HTML/CSS + un script JS), sans outil de construction, hébergé sur **GitHub Pages**.

## Structure

| Fichier / dossier | Rôle |
|---|---|
| `index.html` | Accueil |
| `nos-solutions.html` | Nos solutions |
| `qui-suis-je.html` | Qui suis-je |
| `contact.html` | Contact (le formulaire ouvre la messagerie du visiteur) |
| `politique-de-confidentialite.html` | Politique de confidentialité |
| `nos-services.html` | Redirige l'ancienne adresse vers « Nos solutions » |
| `404.html` | Page « introuvable » |
| `css/style.css` | Styles (couleurs en haut du fichier, dans `:root`) |
| `js/main.js` | Animations, menu mobile, formulaire |
| `images/` | Photos, logo et favicon |
| `documents/lsa_art45.pdf` | Informations LSA art. 45 (mentions légales) |

## Voir le site en local

Ouvrir `index.html` dans le navigateur.

## Publier une modification

1. Créer une branche, faire la modification, ouvrir une **Pull Request**.
2. Relire la PR sur GitHub, puis cliquer sur **Merge**.
3. GitHub Pages remet le site en ligne automatiquement (1 à 2 minutes).
